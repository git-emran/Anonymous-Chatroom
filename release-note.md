# Release Notes

## 🎉 New Features
- **Real-Time Capabilities**: Integrated real-time functionalities for a seamless and instant chatting experience.
- **Self-Destructing Rooms**: Added a new header UI featuring a self-destructing button for enhanced privacy.
- **Dynamic Rooms**: Implemented the ability to create unique, isolated chat rooms by ID.
- **Enhanced Data Fetching**: Routes are now fully integrated with TanStack Query for optimal data fetching and state management.
- **Robust Backend Services**: Successfully connected Redis and Upstash for fast, reliable caching and data storage.

## 🔒 Security & Reliability Improvements
- **Authentication Middleware**: Completed custom authentication middleware to protect routes and ensure secure access.
- **Secure Cookies**: Improved room connection security by properly securing cookies.
- **Data Validation with Zod**: Implemented Zod schema validation across the application (including real-time events) to guarantee strict data integrity and type safety.
- **Architecture**: Stabilized the chatroom building blocks and laid a secure foundation for the application.
